# PhoneCam

Телефон как камера для Windows по Wi-Fi (RTSP + ONVIF).

## Как получить APK (без Android Studio)
1. Создай репозиторий на github.com (кнопка New).
2. Загрузи в него ВСЁ содержимое этой папки (Add file -> Upload files). Папка `.github` должна попасть тоже.
   Если она не загрузилась: Add file -> Create new file, имя `.github/workflows/build.yml`, вставь содержимое файла из архива.
3. Вкладка Actions -> «Build APK» -> дождись зелёной галочки (2-5 минут).
4. Открой завершённый запуск -> внизу Artifacts -> `PhoneCam-apk` -> скачай, распакуй, установи app-debug.apk на телефон.
5. Если сборка красная: открой запуск, скопируй текст ошибки и отправь мне.

## На ПК
Параметры -> Bluetooth и устройства -> Камеры -> Добавить устройство. Телефон и ПК в одной Wi-Fi сети.
Запасной вариант: в VLC открой rtsp://IP_ТЕЛЕФОНА:8554/live (адрес показан в приложении).
